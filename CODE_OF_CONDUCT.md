# Code of Conduct

See [.github/CODE_OF_CONDUCT.md](.github/CODE_OF_CONDUCT.md) for the full code of conduct.

## Summary

- Professional, respectful collaboration is required
- Government-grade professionalism applies to all interactions
- Security vulnerabilities must be reported privately
- Repository integrity and data safety are shared responsibilities
- Harassment, trolling, and abusive behavior are not tolerated
