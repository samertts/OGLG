# AI Permissions

AI may:

- Perform spelling correction
- Perform grammar correction
- Suggest formal governmental wording
- Suggest official templates
- Improve readability
- Detect colloquial language
- Suggest formatting improvements

---

# AI Restrictions

AI MUST NOT:

- Invent facts
- Modify official names
- Modify medical facts
- Modify legal facts
- Modify numerical values
- Modify identifiers
- Auto-send data externally
- Perform autonomous actions
- Override user decisions
- Access internet services
