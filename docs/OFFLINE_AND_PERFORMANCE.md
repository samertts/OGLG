# Offline First Policy

- All core functionality MUST operate fully offline.
- Internet connectivity MUST NEVER be required for system operation.
- No cloud activation systems are allowed.
- No online licensing validation is allowed.
- No remote dependency may block operation.
- Local-first storage is mandatory.
- AI features MUST function locally.
- All critical resources MUST exist locally.

---

# Performance Governance

- Startup time MUST remain under 3 seconds on average governmental hardware.
- RAM usage MUST remain optimized for 4GB RAM systems.
- Idle CPU usage MUST remain minimal.
- Heavy background processes are forbidden.
- Blocking UI operations are forbidden.
- Memory leaks are unacceptable.
- UI freezing is considered a critical defect.
- Large archive handling MUST remain performant.
- System responsiveness MUST remain stable under high archive volume.
