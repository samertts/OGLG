# Code Quality Governance

- Production-ready code only.
- Experimental unstable code is forbidden.
- Hardcoded values are forbidden.
- Centralized configuration management is mandatory.
- Dead code is forbidden.
- Debug leftovers are forbidden in production.
- Magic numbers are forbidden.
- Configuration sprawl is forbidden.
- Consistent coding standards are mandatory.

---

# Version Control Governance

- Git usage is mandatory.
- Main branch stability has highest priority.
- Experimental work MUST use separate branches.
- Major changes MUST use commits.
- Destructive changes require backups.
- Commit history MUST remain meaningful and traceable.
