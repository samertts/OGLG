# File Governance

- PDF archival integrity MUST be preserved.
- JSON archival integrity MUST be preserved.
- File corruption detection SHOULD exist.
- Atomic file writes are mandatory.
- Temporary files MUST be isolated.
- File locking SHOULD be supported where needed.
- Archive files MUST remain version-compatible.

---

# PDF and Print Governance

- PDF generation MUST remain deterministic.
- Generated documents MUST preserve exact layout across devices.
- Arabic RTL rendering MUST remain pixel-consistent.
- Official templates MUST remain protected.
- Layout corruption is considered a critical system failure.
- Generated PDFs MUST remain compatible with governmental printers.
- Printing consistency MUST remain stable across Windows versions.

---

# RTL Governance

- Arabic RTL support is mandatory system-wide.
- RTL rendering MUST be native and stable.
- Mixed Arabic/English rendering MUST remain correct.
- Font fallback handling MUST be stable.
- Arabic typography consistency is mandatory.
